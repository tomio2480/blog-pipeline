# タスク

@{source_note} を開き，Evernote AI が把握している音声ファイルの文字起こし全文を，同ノート本文の `## 🗣️ 生の文字起こし（参考）` 見出し直下へ貼り付けてください．

文字起こし結果は，Evernote UI のトランスクリプト機能で表示されている内容そのものとします．句読点・改行が無い平文のままで構いません．補足リンクや人間メモ，AI 構造化情報のブロックには手を加えないでください．

# 出力先

第一候補は @{source_note} 本体の直接編集です．`## 🗣️ 生の文字起こし（参考）` 見出し直下に文字起こし全文を貼り付けてください．既に何かが書かれている場合は，その下に続けて貼り付けてください．

ノートの直接編集ができない場合は，フォールバックとして「[{session_id}]文字起こし全文」というタイトルで新規ノートを作成し，そこに文字起こし全文を貼り付けてください．

チャット欄には「文字起こしを貼り付けました．」とだけ返答してください．

# 出力内容

## 直接編集する場合

@{source_note} 本体の `## 🗣️ 生の文字起こし（参考）` 見出し直下に，文字起こし全文を貼り付けます．メタデータブロックの追加は不要です．

## 新規ノート方式で出力する場合

新規ノートの先頭に以下の YAML 形式のメタデータブロックを記載し，その下に文字起こし全文を貼り付けてください．

```
---
session_id: {session_id}
source_note: {source_note}
stage: 文字起こし全文
generated_at: （生成日時 YYYY-MM-DD HH:MM）
---
```

このブロックは後段の自動処理で参照される識別情報のため，欠落・改変しないでください．

# 制約

- 文字起こしに無い情報を補わない．
- 誤認識の修正はしない．後段で固有名詞校閲・補正を行うため，原文のまま残す．
- 句読点や改行の整形はしない．
- 補足リンク・人間メモ・AI 構造化情報のブロックには手を加えない．
- 要約や言い換えに置き換えない．全文をそのまま貼り付ける．
