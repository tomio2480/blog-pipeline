# タスク

@{source_note} の文字起こし本文を，ブログ執筆用の素材として構造化してください．補足リンクが添付されていても，本タスクではリンク先の内容には踏み込まず，文字起こし本文の整理に集中してください．

# 出力先

「[{session_id}]構造化」というタイトルで新規ノートを作成し，そこに結果を書き出してください．チャット欄には「構造化ノートを作成しました．」とだけ返答してください．

# 出力内容

新規ノートには以下の順序で内容を書き込んでください．

## メタデータブロック

先頭に以下の YAML 形式のメタデータブロックを記載してください．

```
---
session_id: {session_id}
source_note: {source_note}
stage: 構造化
generated_at: （生成日時 YYYY-MM-DD HH:MM）
---
```

このブロックは後段の自動処理で参照される識別情報のため，欠落・改変しないでください．

## 全体テーマ

1〜2 文で要約してください．

## 主要トピック

トピックごとに `### トピック（短いラベル）` の見出しを立ててください．見出しの下には自然な文章による段落を 1〜2 個書いてください．箇条書きで項目を切り出すことはせず，地の文として書いてください．

段落には以下の要素を可能な限り盛り込みます．

- 文字起こしから読み取れる主張・気付き．
- 本人が口にした表現を根拠とする感情・温度感．語っていない感情は推測しない．
- そのまま記事に使える印象的な言い回しがあれば，地の文に組み込むか引用として残す．
- 関連する具体例や固有名詞．

埋めるべき情報が文字起こしに無い場合は，無理に文字数を埋めようとせず，そのトピック自体を省略してください．

# 制約

- 文字起こしに無い事実情報を補わない．
- 感情の解釈は本人の表現を根拠とする．
- 口語の冗長さは整理してよいが，語り口・思考の揺れは残す．
- 装飾的な形容詞を抑え，客観的に整理する．
- 表組みは使わない．段落と見出しのみで構成する．
