# タスク

@{source_note} の文字起こしから固有名詞を抽出し，校閲してください．

# 参照優先順位

1. @固有名詞マスター ノート内の登録表記（存在する場合）．
2. @{source_note} 内の補足 Web リンクの本文．
3. Web 検索（Tools メニューから利用）．

上位の参照先で見つかった表記が正解とします．下位で異なる表記が見つかっても，上位を優先してください．

# 校閲対象

- 人物名（特に日本人名のカナ・漢字）．
- コミュニティ名・勉強会名・イベント名．
- 製品名・サービス名・技術名．
- 地名（市町村名・施設名）．

# 出力先

「[{session_id}]固有名詞校閲」というタイトルで新規ノートを作成し，そこに結果を書き出してください．チャット欄には「固有名詞校閲ノートを作成しました．」とだけ返答してください．

# 出力内容

## メタデータブロック

先頭に以下の YAML 形式のメタデータブロックを記載してください．

```
---
session_id: {session_id}
source_note: {source_note}
stage: 固有名詞校閲
generated_at: （生成日時 YYYY-MM-DD HH:MM）
---
```

このブロックは後段の自動処理で参照される識別情報のため，欠落・改変しないでください．

## 修正した固有名詞

修正した語ごとに `### 修正後の表記` の見出しを立ててください．見出し文字列には修正後の表記そのものを書きます．見出しの下に以下の箇条書きを記載してください．

- 原文：文字起こしに現れた誤った表記．
- 根拠（参照先名）：固有名詞マスター名・補足リンク名・Web 検索結果のいずれか．

修正が無かった場合は，このセクション自体を「修正なし」と 1 行で記載してください．

## 要確認の固有名詞

確定できなかった語ごとに `### 表記` の見出しを立て，見出し文字列には対象表記を書きます．見出しの下に以下の箇条書きを記載してください．

- 出現文脈：短い引用．
- 不明な理由：上位参照先で確認できない理由を 1〜2 文で．

該当が無い場合は，このセクション自体を「要確認なし」と 1 行で記載してください．

## 表記揺れ候補

揺れている語ごとに `### 統一推奨表記` の見出しを立てます．見出し文字列には統一すべき表記を書きます．見出しの下に以下の箇条書きを記載してください．

- 出現バリエーション：文字起こしに現れたバリエーション一覧．

該当が無い場合は，このセクション自体を「表記揺れなし」と 1 行で記載してください．

## 固有名詞マスターへの登録推奨

新規に登録すべき語を箇条書きで列挙してください．該当が無い場合は「登録推奨なし」と 1 行で記載してください．

# 制約

- 参照先で確認できない固有名詞を推測で置き換えない．
- Web 検索の結果が複数候補ある場合は「要確認」とする．
- 似た名前の有名人と同一視しない．
- 表組みは使わない．見出しと箇条書きのみで構成する．
